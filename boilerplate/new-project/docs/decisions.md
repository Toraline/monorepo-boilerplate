# Decisions

Technical decisions of this repository, newest first. An agent that decides an open choice writes it here, and lists it in the pull request.

Format of one entry:

```
## <YYYY-MM-DD> - <short title> (<TICKET-ID>)
- Decision: <what was chosen>
- Why: <one or two sentences>
- Alternatives: <what was not chosen, one line each>
- Decided by: <the person, or "agent, to be confirmed in review">
```

This project was created from the Toraline monorepo boilerplate. The decisions that the boilerplate made before that (the versions, the database, the login, the languages, the theme, the commands) are in the file `docs/decisions.md` of the repository `Toraline/monorepo-boilerplate` on GitHub.

Write the decisions of this project below this line, newest first.
